# ComfyUI code: rules the code doesn't show locally

- **This code runs in the browser and on the server** (the work queue builds and sends jobs, `src/lib/worker/pictures.ts`). No `window`, canvas or `createImageBitmap` without a guard; `uploadStart` falls back to `imageSize` on the server. A job reaches the server as a `JobSpec` (`jobSpec.ts`): pictures are source strings, and a server-side `PaintedArea` has no strokes, so anything computed from strokes (like `maskBounds`) is done in `toSpec` and carried in `SpecMask`.
- **Whose graph it is.** A pasted workflow with placeholders (`{{prompt}}` …) is the author's: never add nodes to it (only `{{mask}}` is filled). Ours, which may be rewritten: the built-in workflows, a pasted workflow without placeholders (`describeWorkflow(wf).mode === "detected"`), and the model-family workflows (`drawModels.ts`). A pasted workflow overrides a preset's family.
- **Never mutate `BUILTIN_*`** (`fillSettings` copies; tests check). Keep existing node ids stable (tests and links use them); new nodes get ids starting `storytime_`. Without a mask or references, a workflow must come out exactly as before: each change to the graph needs a test that says so.
- **Every new node class goes in `NODES` in `tests/e2e/fakeComfy.mjs`.** Core nodes such as `DifferentialDiffusion` must not go in a family's `nodes` list, or old ComfyUIs stop drawing at all.
- **`sameJob` is the job's identity** (quick clicks with the same key gather into one job, and the queue matches jobs by it). Anything that changes the result must be in it: mask `id`, refs (key, role, weight), `fill`, `temporary`, `session`/`base`.
- **ComfyUI quirks:** `KSampler` with `denoise` 0.5 still runs the whole schedule's time (`partialSteps` switches to `KSamplerAdvanced` for that). `ImageCompositeMasked` repeats `source`, not `destination`, to the batch size, and resizes `mask` to `source`. Older ComfyUIs' `/interrupt` stops whatever is running, whichever id is given (see `cancelPrompt`).
- **ComfyUI may be shared** with other StoryTimes. Jobs carry `extra_data.storytime` (`JobTag`) with this StoryTime's `instance` (`src/lib/instance.ts`); only jobs with our instance (or none, for a chapter that exists here) are shown, recorded or stopped.
- **Pictures are shown from ComfyUI's `/view` straight to the browser**, so the browser must reach ComfyUI too; making them goes through the server.
- **Nothing here has been run against a real ComfyUI** except what `TODO.md` says was checked. The fake doesn't run graphs, so browser tests only prove a job is accepted; check graph shapes in `tests/unit/comfy-workflow.test.mts` and `tests/unit/draw-models.test.mts`.
- Tests: unit `comfy-workflow`, `draw-models`, `job-spec`, `mask`, `inpaint-region`, `pictures`; browser `illustrate-*`, `refine-*`, `cover-make`, `codex-pictures`, `picture-queue*`.
